# Film workflow

For film creation, continuation, scripts, storyboards, production assets, creative repairs, or episode delivery, read `skills/film-director/SKILL.md`. Follow its relative references only for the current stage. For production batches, also read `skills/loop-engineer/SKILL.md`.

This is a reusable kit. Start a new story with its own state and real user decisions. The bundled provider, browser, cover, and language choices are defaults that the current user can override; they do not authorize spending, service terms, publishing, or access to another person's accounts. Check actual tools and permissions before promising media generation.

Keep this repository for skills, workflow, and helper code. Store generated films and project records in a separate project folder. Skill packaging and unrelated software maintenance do not invoke film review stages.
