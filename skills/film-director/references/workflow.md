# Reusable production workflow

Use this guide when starting production or choosing how to repair a shot. The parent skill owns creative review; this guide supplies reusable working defaults. Current user instructions and authorized budget take precedence.

## Tools and scope

Use Meta first for a new video shot, then Google Flow for a failure that needs a different method, then Thai AI Passport if available and authorized. Reuse existing attempts and evidence; do not submit duplicate attempts merely to fill a record. Use only the current user's accounts, authorized tool tier, and budget. A service not available in the environment is a limitation, not permission to substitute another provider silently.

Agree on the next delivery unit. Work episode by episode when requested, close its current edit before branching into optional work, and honor explicit requests to defer covers or localization. Within an authorized series batch, finish each review cut and continue to the next episode unless a decision blocks the dependent work.

## Identity and continuity

Attach the approved scene board and compatible character/state references as real generation inputs. Lock face, age, hair, wardrobe, supernatural state, room geography, props, events, and reveal order. Inspect faces after turns as well as at the first frame.

When side/back angles drift, prepare a corrected scene image with the approved identity. If supported, use matching start/end frames with a clear face in the end frame and direct the visible transition. A character sheet named in a prompt is not an attachment. A normal face must not override an approved faceless ghost state.

For mirrors, prepare an explicit approved or restorative board showing the intended person, reflected image, geometry, and supernatural rule. Use it as actual input instead of repeating a prompt that left reflection ambiguous.

## Bounded repair and useful progress

Count cumulative attempts across prompt/file versions, providers, and reviewers. Before retrying, identify the defect's likely cause and what changes to address it. After two consecutive attempts fail on the same defect with the same method, change the method, simplify the staging without changing the accepted event, use an authorized alternative, or preserve a clearly labeled unresolved shot.

Select useful ranges from existing footage before generating more. Preserve critical identity, supernatural state, clothing, setting, event meaning, reveal order, and approved sound. Keep minor deviations within the current user's tolerance and record them for later; a request for an early review cut can permit small imperfections, but it does not make a wrong event pass.

Use a held scene image only when the current user explicitly permits that fallback. Name its shot ID, duration, and missing movement in the review handoff. Record it as a still; missing motion remains missing.

Lock passed shots. Recheck them only when an affected source, edit boundary, or new defect warrants it. Keep one current state and shot list, link evidence instead of copying the whole story repeatedly, and use delegation only when authorized and useful for a concrete task or independent check.

Each working segment should improve inspectable media: a new clip, a selected take/trim, or an assembled cut. If only paperwork advances, change the approach. Report exact output, usable shots, unresolved shots, and measured credit use when available; mark unknown spend unknown and do not invent token or credit counts.
