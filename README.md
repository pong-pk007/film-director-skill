# Film Director Kit — สั่ง AI ทำหนังเป็นขั้นตอน

ชุดสกิลและเวิร์กโฟลว์สำหรับให้ AI ช่วยทำหนัง ตั้งแต่บท คาแรคเตอร์ชีท สตอรี่บอร์ด ภาพเคลื่อนไหว เสียง ตัดต่อ จนถึงชุดส่งมอบ โดยมีจุดให้เจ้าของเรื่องตรวจและเลือกก่อนผลิตจริง

แพ็กนี้มีเฉพาะกระบวนการและเครื่องมือตรวจงาน ไม่มีเรื่อง ตัวละคร สื่อ บัญชี หรือประวัติการอนุมัติจากโปรเจกต์ต้นทาง แต่ละคนเริ่มเรื่องและเลือกเครื่องมือ/งบของตัวเอง

## เริ่มใช้กับ AI ได้ทันที

ดาวน์โหลด ZIP หรือ clone repository นี้ เปิดโฟลเดอร์ใน AI coding agent ที่อ่านไฟล์ได้ แล้วส่งข้อความนี้:

```text
อ่าน AGENTS.md และ skills/film-director/SKILL.md ใน repo นี้
แล้วใช้เวิร์กโฟลว์ทำหนังตามบรีฟของฉัน:
เรื่อง: [ไอเดียหรือเรื่องย่อ]
ความยาว: [เช่น 1 ตอน 60–80 วินาที]
ภาพ: [เช่น การ์ตูนไทย แนวตั้ง 9:16]
โทน: [หลอน / โรแมนติก / ดราม่า]
งบและเครื่องมือที่อนุญาต: [ระบุของฉัน]
เริ่มทำบทให้ฉันตรวจ แล้วเดินตามขั้นของสกิล
ใช้ไฟล์สถานะชุดเดียว และอย่าเรียกภาพนิ่งว่าภาพเคลื่อนไหวผ่าน
```

ไม่ต้องติดตั้งสกิลแบบ global เพื่อเริ่มด้วยวิธีนี้ สกิลเป็นคำสั่งให้ AI ทำงาน ไม่ใช่โปรแกรมสร้างหนังอัตโนมัติ และไม่เพิ่มเครื่องมือที่ AI ตัวนั้นยังไม่มี

## ติดตั้งเป็นสกิลของ Codex

ต้องมี Python 3.11 ขึ้นไป รันจากโฟลเดอร์ repo:

```powershell
python scripts/install.py
```

ตัวติดตั้งคัดลอก `film-director` และ `loop-engineer` ไปที่ `$CODEX_HOME/skills` หรือ `~/.codex/skills` ถ้าไม่ได้ตั้ง CODEX_HOME และจะหยุดก่อนคัดลอกหากชื่อใดมีอยู่แล้ว จากนั้นเปิด session ใหม่เพื่อให้ตรวจพบสกิล

เลือกปลายทางอื่นได้:

```powershell
python scripts/install.py --destination ./my-agent-skills
```

เรียกใช้ด้วย `$film-director` พร้อมบรีฟของคุณ สำหรับ AI ที่ใช้ระบบสกิลต่างกัน ให้ AI อ่านไฟล์ `SKILL.md` และเอกสารที่ลิงก์โดยตรง ไม่ต้องสมมติว่ารองรับคำสั่ง `$...`

## เส้นทางงาน

**บท → วิธีเล่า → เลือกตัวละคร → สตอรี่บอร์ดทั้งขอบเขต → ผลิต → ตัดต่อ → ตรวจ → ส่งมอบ**

ผู้ใช้ต้องได้เห็นสิ่งที่อนุมัติจริง การยอมรับบทไม่ได้อนุมัติภาพที่ยังไม่เคยเห็น เมื่อผ่านแล้วให้ใช้การเลือกเดิมต่อ แก้เฉพาะส่วนที่ได้รับผลกระทบ

- [สกิลผู้กำกับ](skills/film-director/SKILL.md): เรื่อง ภาพ การแสดง เสียง และขั้นตรวจของผู้ใช้
- [เวิร์กโฟลว์ผลิตและคุมต้นทุน](skills/film-director/references/workflow.md): ลำดับเครื่องมือ ความต่อเนื่อง การลองแก้ และส่งฉบับให้ตรวจ
- [คู่มือผลิต](skills/film-director/references/production-guide.md): อ้างอิงจริง ตรวจช็อต เสียง และตัดต่อ
- [แพ็กเก็ตและตัวตรวจ](skills/film-director/references/production-packet.md): รูปแบบข้อมูลและวิธีรัน
- [งานหลังตัดต่อ](skills/film-director/references/postproduction-guide.md): ปก เสียงอังกฤษ และซับ/ข้อความไทยอังกฤษ
- [Loop Engineer](skills/loop-engineer/SKILL.md): วงจรลอง ตรวจ แก้ และเดินงานต่อ

ค่าเริ่มต้นของแพ็กคือเสียงจาก Google AI Studio และงานเว็บผ่าน in-app browser ของ Codex ส่วนวิดีโอใช้ Meta → Google Flow → Thai AI Passport เมื่อบัญชี เครื่องมือ และงบของผู้ใช้รองรับ ปรับได้ตามคำสั่งเจ้าของเรื่องก่อนเริ่มผลิต

ชุดส่งมอบเต็มมี MP4 ปกแบบการ์ตูนผีไทย เสียงอังกฤษ MP3 และ SRT/TXT สองภาษา เป็นค่าเริ่มต้นของแพ็ก ผู้ใช้สั่งแค่บท แค่ตัดต่อ หรือเฉพาะ MP4 ได้ ชนิดปกและภาษาปรับตามงาน สกิลไม่ได้ให้สิทธิ์ซื้อเครดิต สมัครบริการ ยอมรับเงื่อนไข หรือเผยแพร่แทนผู้ใช้โดยอัตโนมัติ

## สิ่งที่ต้องเตรียม

- AI agent ที่อ่าน/เขียนไฟล์และใช้เครื่องมือได้ งานเว็บต้องมี browser control และบัญชีบริการของผู้ใช้
- เครื่องมือสร้างภาพสำหรับคาแรคเตอร์ชีท/สตอรี่บอร์ด/ปก เช่น imagegen ที่มีอยู่ในสภาพแวดล้อมของ agent
- บริการสร้างวิดีโอและเสียงที่เข้าถึงได้จริง การดาวน์โหลดและเครดิตฟรีขึ้นกับบัญชีและข้อกำหนดปัจจุบันของแต่ละบริการ
- Python 3.11+ สำหรับตัวตรวจ, FFmpeg/ffprobe สำหรับตัดต่อและตรวจสื่อ ตั้ง PATH หรือส่ง `--ffprobe` ให้ตัวตรวจ

หากขาดเครื่องมือ ให้ AI บอกขั้นที่ทำได้และข้อจำกัดจริง ไม่มีไฟล์เสียง/คลิปสำเร็จรูปหรือ API key อยู่ในแพ็กนี้ การอ่านคำสั่งเฉย ๆ ไม่ใช่หลักฐานว่าสร้างหรือตรวจสื่อแล้ว

## ตรวจเครื่องมือที่แนบมา

```powershell
python -m unittest discover -s skills/film-director/scripts/tests -v
python skills/film-director/scripts/check_production.py --help
```

ตัวตรวจเช็กไฟล์ hash ขนาดภาพ และโครงสร้างหลักฐาน ไม่ได้ตัดสินความสนุกหรือยืนยันว่าได้ฟัง/ดูหนังจริง ต้องเก็บการตรวจภาพ เสียง และจังหวะตามความสามารถที่มี

Repository นี้เป็น private ผู้ที่จะเปิดหรือ clone ต้องได้รับสิทธิ์จากเจ้าของก่อน
